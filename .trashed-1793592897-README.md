# Digital Seva Point — Pro Cyber Café Website

## Run locally
1. Install Node.js 18+
2. In this folder run: `npm install`
3. Run: `npm start`
4. Open: `http://localhost:3000`
5. Admin orders: `http://localhost:3000/admin`

## Production
Deploy the Node/Express app on a server. Use HTTPS so browser geolocation works reliably. Replace the business name, phone, address and service list in `public/index.html` / `public/app.js`.

## Important
The included location capture uses browser permission and stores latitude/longitude with an order. For a real business, add authentication, encrypted database storage, file upload storage, backups, rate limiting, HTTPS, and an order notification integration (WhatsApp/SMS/email). Never ask customers for Aadhaar/ID OTPs, PINs or passwords.
